# Gdg Event Sparkle

Build a beautiful, modern, and mobile-responsive event webpage for a Google Developer Groups (GDG) event. 

Use standard GDG branding elements and colors (Google blue, red, yellow, and green accents on a clean white/light gray background). 

Include the following structured sections:

1. Header/Navbar: With a placeholder GDG logo text and smooth scrolling links to sections.

2. Hero Section: An eye-catching title like "GDG DevFest 2026", a brief catchy description, date/time/location badges, and a prominent "Register Now" button that scrolls down to the form.

3. Event Details/Schedule: A clean visual timeline or grid displaying 3-4 dummy speaker sessions and topics.

4. Registration Form: A functional-looking dummy form containing input fields for Full Name, Email Address, Role (Student/Professional dropdown), and a "Submit Registration" button. When the user clicks submit, show a beautiful, interactive "Success! You're registered." toast notification or pop-up modal.

Make sure the entire layout looks completely natural and easy to navigate on both desktop screens and mobile smartphones.
